# Аэродром Липки — музейная экспозиция: программный анализ контуров ВС

Источник изображения: чистый скриншот Яндекс.Карт (1645×1845 px, ~6.89 px/м).
Сопоставление с реестром бортов aviapix.ru (GPS-координаты экспонатов) и списком экспозиции (aircraft-museum.ucoz.ru, kpopov.ru).

Углы: ось фюзеляжа — азимут 0–180° (0° = север, по часовой); нос — азимут 0–360° (направление на нос).
«Правило носа»: для реактивных — дальний от центра масс конец (стреловидные крылья смещают центр масс к хвосту); для поршневых/планеров — сужение профиля; для вертолётов — тонкая хвостовая балка.
