# B-2 — источники данных

Задача B-2 расширяет существующую карту на том же источнике, что и центральный
пилот. Смена/обновление OSM-снапшота отделяется от расширения территории: иначе
регрессии нельзя будет отличить от изменений исходных данных.

## Основной источник (закреплён)

| Поле | Значение |
| --- | --- |
| Файл | `data/raw/Minsk.osm.pbf` |
| Размер | 35 145 284 байт |
| SHA-256 | `DA3CCDB434F90D6A55723950167E9D93DBBB27FF063A8D8DA3588A74B61663F8` |
| Replication timestamp | `2026-10-24T00:00:00Z` |
| Header bbox | lon 27.2770…27.9340, lat 53.7380…54.0500 |
| Провайдер | [BBBike extract service](https://extract.bbbike.org/) (Minsk), см. [`docs/DATA_SOURCES.md`](../DATA_SOURCES.md) и `data:download` |
| Лицензия | © OpenStreetMap contributors, ODbL 1.0 |

Проверки, которые выполняет пайплайн:

* `scripts/ingest/extract.py` читает header bbox PBF и падает, если окно извлечения
  выходит за него;
* окно извлечения строится из `CITY_BOUNDS_M` (локальные метры) точным
  преобразованием UTM 35N → WGS84 + `CITY_HALO_M = 1000` м, без приближения
  «метров на градус»;
* `scripts/qa/b2_area_schema.py` пересобирает кольцо МКАД и кладбище прямо из PBF
  и пишет [`area.json`](area.json) + [`coverage.svg`](coverage.svg).

Проверка целостности:

```powershell
Get-FileHash data\raw\Minsk.osm.pbf -Algorithm SHA256
```

## Когда обновлять снапшот

Только отдельным изменением, после закрытия B-2, с одновременным обновлением
`area.json` (sha256 + timestamp) и перегенерацией датасета. Обновление PBF в
рамках B-2 запрещено планом: сначала расширение на текущем снапшоте.

## Источники референса (не входят в B-2)

[Isometric Warsaw](https://bedirhanyildirim.com/warsaw-izo/) использует более
богатый набор данных: LoD2-здания, 3D-деревья, рельеф (NMT) и ортофото от GUGiK
(`geoportal.gov.pl`), GTFS-расписания ZTM Warszawa и PKP PLK, погоду
Open-Meteo. Это отдельные пункты беклога (рельеф/DEM — известное ограничение
[`docs/LIMITATIONS.md`](../LIMITATIONS.md), транспорт/погода — отдельное
расширение), а не требования B-2. Сравнение с референсом идёт по
пользовательскому результату, не по совпадению источников.
